대상을 선택하고, 같은 화면에서 상세·로그를 확인한 뒤 조작하도록 흐름을 연결했습니다.

  • 큰 숫자 카드 대신 비교하기 쉬운 목록과 인라인 요약
  • 중립적인 표면, 한 가지 강조색, 의미가 있을 때만 쓰는 상태색
  • 행 전체 선택, 목록 옆 상세·로그, 검색·필터 맥락 유지
  • 등록 후 새 항목 선택, 입력 초안 복원, 상태별 조작과 결과 표시

모든 값은 디자인 검토용 샘플입니다. 버튼은 이 목업의 데이터만 변경하며 실제 프로세스, 작업, 데몬에 연결되지 않습니다. 하단 도구에서 오류·빈 상태와 테마를 비교할 수 있습니다.
